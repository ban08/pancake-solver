# Pancake Puzzle Project

Python project for FEUP Assignment 1, Topic 1: One-Player Solitaire Games.

## Features
- Pancake puzzle state representation
- Human play mode
- Solver mode
- Hint mode
- Uninformed and informed search
- File input/output
- GUI
- Benchmarking

## Algorithms
- BFS
- DFS
- Iterative Deepening
- Uniform Cost Search
- Greedy Search
- A*
- Weighted A*

## Heuristics
- Gap heuristic
- Additional baseline heuristics
